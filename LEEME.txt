CARPETA LISTA PARA GITHUB PAGES

Subí directamente estos elementos al repositorio:

1. index.html
2. La carpeta assets completa
3. El archivo .nojekyll

No necesitás instalar Node, Vinext ni ningún programa.

Para verla antes de subirla, abrí index.html con doble clic.

La presentación está optimizada para proyección en pantalla 16:9 y se controla con:
- Los botones de flecha que aparecen abajo.
- Las teclas de flecha izquierda y derecha.
- La barra espaciadora para avanzar.
- Un gesto horizontal en celulares.
- El botón Pantalla completa en computadoras.

Antes del encuentro todavía conviene completar:
- El enlace definitivo de Mentimeter.
- Los testimonios reales de estudiantes y docentes.
- Los enlaces o archivos de videos, reel y aula Moodle.

IMPORTANTE
El archivo index.html y la carpeta assets deben quedar en la raíz del repositorio,
no dentro de otra carpeta. Si GitHub Pages muestra una pantalla blanca, verificá
que index.html no esté vacío y que tenga un tamaño cercano a 39 KB.
